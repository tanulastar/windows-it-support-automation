# Windows IT Support Automation Toolkit

## Overview
A collection of PowerShell scripts designed to
simplify common Windows IT support and administration tasks.

## Features
- Collect Windows system information.
- Monitor available disk space.
- Test network connectivity.
- Simplify routine IT diagnostics.

## Technologies
- PowerShell
- Windows Administration
- Windows Management Instrumentation (WMI/CIM)

## Usage
Run PowerShell as appropriate for your permissions
and execute the scripts individually.

## Purpose
This project demonstrates practical IT support,
system administration, and scripting automation skills.
